# Notice

Frac is a focused fork and clean extraction built from [Skybridge](https://github.com/alpic-ai/skybridge), an open-source framework by the [Alpic](https://alpic.ai) team for building ChatGPT and MCP Apps.

We have used Skybridge in production, and among the MCP Apps frameworks we evaluated, it provided the strongest foundation for the direction we want to take Frac. This project preserves that foundation while reshaping the package name, scaffolding, documentation, local testing story, and Fractals workflow around Frac's goals.

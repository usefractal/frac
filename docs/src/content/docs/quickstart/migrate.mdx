Already have an app built with the [OpenAI Apps SDK](https://developers.openai.com/apps-sdk/) or [`@modelcontextprotocol/ext-apps`](https://github.com/modelcontextprotocol/ext-apps)? The frac Skill can migrate it for you — it teaches your coding agent the full frac framework so it can scaffold, rewrite, and wire up your project automatically.

## Install the skill

<CodeGroup>
```bash npm
npx skills add usefractal/frac -s mcp-app-builder
```
```bash pnpm
pnpm dlx skills add usefractal/frac -s mcp-app-builder
```
```bash yarn
yarn dlx skills add usefractal/frac -s mcp-app-builder
```
```bash bun
bunx skills add usefractal/frac -s mcp-app-builder
```
```bash deno
deno run -A npm:skills add usefractal/frac -s mcp-app-builder
```
</CodeGroup>

Agent install metadata:

- Repository: `usefractal/frac`
- Skill path: `skills/mcp-app-builder/SKILL.md`
- Skill name: `mcp-app-builder`
- Install command: `npx skills add usefractal/frac -s mcp-app-builder`

## Prompt your agent

```
Migrate my app to @usefractal/frac
```

That's it. Once migrated, keep using the Skill for ongoing development: brainstorming ideas, designing views and tools, running the dev server, debugging, and preparing for deployment.

Use `server.wormhole()` when a tool and its widget need to share live state after the initial tool result has rendered. A wormhole creates a named, token-protected channel backed by the frac platform.

Wormholes are useful for dashboards, boards, editors, and other views where the tool should initialize state and the widget should keep receiving updates.

<Info>
Wormhole WebSocket URLs are private. frac returns the URL in tool result metadata so the widget can connect without exposing the token to the model.
</Info>

## Import

```ts
import { McpServer } from "@usefractal/frac/server";
```

<Note>
If you're deploying on Fractal, the runtime provides what wormholes need. If you're deploying somewhere else, set `FRACTAL_TOKEN` in the server environment.

```bash
FRACTAL_TOKEN=...
```
</Note>

## Basic usage

```ts
import { McpServer } from "@usefractal/frac/server";
import { z } from "zod";

const server = new McpServer({
  name: "board-app",
  version: "1.0.0",
});

const board = server.wormhole({
  name: "board",
  stateSchema: z.object({
    selectedId: z.string().nullable(),
    filters: z.object({
      projectId: z.string().optional(),
    }),
  }),
  defaultState: {
    selectedId: null,
    filters: {},
  },
  ttl: 3600,
});

board
  .widget({
    component: "Board",
    description: "Interactive project board",
  })
  .tool(
    {
      name: "show_board",
      description: "Open a live project board",
      inputSchema: {
        projectId: z.string(),
      },
    },
    async (wormhole, args) => {
      wormhole.state.selectedId = null;
      wormhole.state.filters.projectId = args.projectId;

      await wormhole.message.send({
        type: "opened",
        projectId: args.projectId,
      });

      return `Opened board for ${args.projectId}`;
    },
  );
```

After the handler finishes, frac validates the state with `stateSchema` and syncs it to the platform if it changed.

## Configuration

```ts
server.wormhole({
  name: string,
  stateSchema: z.ZodType<TState>,
  defaultState: TState,
  ttl?: number,
});
```

| Option | Type | Description |
|--------|------|-------------|
| `name` | `string` | Stable wormhole name. This is scoped by the platform to the current organization. |
| `stateSchema` | `z.ZodType<TState>` | Zod schema used to validate state before sync. |
| `defaultState` | `TState` | Initial state for the wormhole. Include nested object containers you plan to mutate. |
| `ttl` | `number` | Optional token lifetime in seconds. Defaults to the platform token endpoint behavior. |

## `widget()`

Attach a view to the wormhole tool.

```ts
board.widget({
  component: "Board",
  description: "Interactive project board",
});
```

The config accepts the same view options as `registerTool({ view })`.

## `tool()`

Register a tool whose handler receives the wormhole first and tool args second.

```ts
board.tool(config, async (wormhole, args, extra) => {
  wormhole.state.selectedId = args.itemId;
  return "Updated board";
});
```

The handler receives:

| Parameter | Description |
|-----------|-------------|
| `wormhole` | Typed wormhole context for state, messages, token minting, and URL creation. |
| `args` | Parsed tool arguments from `inputSchema`. |
| `extra` | MCP request context, matching `registerTool`. |

## Wormhole context

```ts
type WormholeToolContext<TState> = {
  name: string;
  state: TState;
  message: {
    send(message: unknown): Promise<void>;
  };
  token(options?: WormholeTokenOptions): Promise<WormholeToken>;
  url(options?: WormholeTokenOptions): Promise<string>;
  setState(state: TState): void;
};
```

### `state`

`state` is a tracked proxy of your typed state object.

```ts
wormhole.state.selectedId = "item_123";
wormhole.state.filters.projectId = args.projectId;
```

frac syncs the full state after the handler resolves.

<Warning>
Nested object containers must exist in `defaultState` before you mutate them. For example, use `defaultState: { filters: {} }` before assigning `wormhole.state.filters.projectId`.
</Warning>

### `message.send()`

Broadcast a transient message to connected widgets. Messages are not persisted.

```ts
await wormhole.message.send({
  type: "highlight",
  itemId: "item_123",
});
```

### `setState()`

Replace the full state explicitly.

```ts
wormhole.setState({
  selectedId: null,
  filters: {},
});
```
